# Spreadsheet Plugin — Examples

Open this file and move your cursor **outside** a table to see it rendered as an interactive grid.

---

## Basic table

Click any cell to edit. Press Enter or Tab to confirm.

## Tips

- Click **Edit raw** to see the underlying Markdown table syntax
- Move your cursor into the table to edit the raw Markdown directly
- All edits are saved back as standard Markdown — works in any editor
