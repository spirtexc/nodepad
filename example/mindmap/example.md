# How to Use Mindmap

## Open a file with headings
## Click the tree icon in the dock
## The mindmap renders instantly

# Tips

## Keep headings short for cleaner nodes
## Use 2 to 3 levels for best readability
## Zoom out with scroll if the tree is large
